# WSV / www.vamrss.com Launch Build v3.9.4

## Close Scroll Position

- When an expanded work item is closed on the public top page, the closed item scrolls to the top of the viewport.
- When an expanded series item is closed on the public top page, the closed item scrolls to the top of the viewport.
- Nested work details inside series also scroll the relevant row to the top when closed.
- The admin list uses the same close-scroll behavior.

No additional SQL is required if the v3.8.3 SQL patch has already been applied.
